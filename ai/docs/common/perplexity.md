## Skills
- For web search, use the `perplexity` skill and its `pplx-search` CLI. The skill
  ships from https://github.com/kevinmcmahon/pplx-search, not from this repo:
  Claude Code loads it as a plugin, while Codex and OpenCode read it from the
  shared `~/.agents/skills/perplexity` store. `pplx-search` is on `PATH`.
